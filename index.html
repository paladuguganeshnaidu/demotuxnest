Powerful Features

Everything you need to manage modern infrastructure

SSH Connection Manager

Organize, search, and connect to hundreds of servers with smart grouping, key management, and one-click access.

Terminal Multiplexing

Split panes, persist sessions, and automate workflows with a built-in terminal that feels native on every platform.

Sync & Backup

Encrypted sync of configs, keys, and aliases across devices. Zero-knowledge architecture — your data, your control.

Scripting & Automation

Write once, run everywhere. JavaScript/TypeScript API for custom workflows, deployments, and integrations.

Plugin Ecosystem

Extend with community plugins or build your own. First-class VS Code extension for seamless editor integration.

Security First

Hardware key support, agent forwarding, audit logs, and team access controls. SOC2-ready architecture.
